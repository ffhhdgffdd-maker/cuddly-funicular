# WolFox Android No-Root

هذا الفرع مخصص لنسخة Android مستقلة من WolFox.

## قواعد التنفيذ
- بدون Root.
- بدون اشتراط Developer Options أو USB debugging أو ADB أو Shizuku.
- استخدام Android APIs الرسمية فقط.
- أي وظيفة لا يسمح بها Android لتطبيق عادي لا يتم تمثيلها كوظيفة عاملة.
- دعم اختيار التطبيق المستهدف ضمن ما تسمح به Package Visibility وواجهات Android الرسمية.
- حفظ التطبيق المستهدف والحالة محلياً.
- البناء والاختبارات مستقلة تماماً عن iOS.

## هيكل مقترح
- app: واجهة WolFox.
- core: الحالة والتخزين والمنطق المشترك الخاص بأندرويد.
- features/location: إمكانات الموقع المسموح بها رسمياً.
- features/camera: اختيار/حفظ الصور ودورة حياة الكاميرا.
- features/bluetooth: Bluetooth APIs الرسمية.
- features/targets: اختيار وعرض التطبيق المستهدف ضمن صلاحيات النظام.
- diagnostics: تشخيص نسخة الاختبار فقط.

> لا تعتبر أي وظيفة متوافقة مع جهاز أو إصدار Android فعلي حتى يتم اختبارها على جهاز حقيقي.
