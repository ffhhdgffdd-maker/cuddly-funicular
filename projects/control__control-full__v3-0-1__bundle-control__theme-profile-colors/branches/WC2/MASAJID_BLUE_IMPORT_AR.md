# WolFox 3.0.0 — نسخة مساجد بالتصميم الأزرق

التطبيق المستهدف: `sa.gov.moia.mosques-2`، ملف التعريف `mosques-full`.

- خلفية كحلية وأزرار زرقاء ونصوص أخف سطوعًا.
- أزيل تبويب الإعدادات من شريط الأقسام. يوجد زر الإعدادات وزر خروج من التطبيق في نهاية القسم الأول (الخريطة).
- الإعدادات تحتوي تشغيل وإيقاف الموقع والمعرّف والبلوتوث والكاميرا والجدولة واختصار الصوت، إضافة إلى خيارات الأيقونة والمنيو ومدخل التفعيل والكاميرا.
- عمليات حفظ المعرّف وتعديله وحذفه وإعادة تعيينه، وتغييرات مفاتيح الإعدادات، تتطلب تأكيدًا صريحًا يوضح أن التطبيق سيُغلق بعد حفظ التغيير. بعد الإغلاق يعيد المستخدم فتح التطبيق من الأيقونة؛ لا يوجد وعد بإعادة الفتح تلقائيًا.
- استيراد المعرّف متاح من ملف GPS Plus v4 المشفر بطريقة XOR 0x5A، أو ملف WolFox JSON، أو UUID نصي، أو الحافظة. يعرض المعرّف للمراجعة ولا يفعّله تلقائيًا.
- في ملف GPS Plus تُختار قيمة `custom_uuid` إذا كانت موجودة، وإلا `idf`. لا يعاد تخزين محتوى Keychain أو معرّفات خدمات الحماية من الملف.
- القراءة المباشرة من التطبيق تبحث عن appUUID وخدمة flutter_udid ضمن صلاحيات التطبيق الحالية؛ عند عدم توفرهما تُوضح بدائل الاستيراد. لا يضمن تغيير الألوان أو نجاح البناء توفر Keychain على الجهاز.
- التصدير ينسخ UUID أو ينشئ ملف JSON يحتوي UUID ومعرّف التطبيق فقط. يمنع استيراد ملف WolFox لتطبيق آخر.
- الحد الأقصى لملف الاستيراد 64 كيلوبايت. تُرفض الملفات التالفة والصيغ غير المعروفة والمعرّفات غير الصحيحة.

البناء ينتج DEB Rootful وRootless وdylib لمعمارية arm64. هذه ليست IPA موقّعة. اختبارات المحلل تعمل على Foundation في macOS، ثم تجري اختبارات Linux والترجمة والتغليف على GitHub Actions. التشغيل والتفاعل الفعلي على iOS يحتاجان تجربة الجهاز.
