# WolFox Lite 2.0.0

نسخة خفيفة مخصصة للموقع، مع حفظ المفضلة والجداول والإعدادات وبيانات التفعيل عند التحديث.

## التفعيل والأمان

- واجهة مختصرة لإدخال الكود، زر لصق خارجي وأيقونة نسخ داخل الخانة.
- نتيجة النجاح أو الفشل في إشعار مستقل؛ زر «موافق» يفتح اللوحة بعد النجاح.
- عرض الباقة وتاريخ البداية والانتهاء والمدة المتبقية.
- حفظ الكود وبيانات الجلسة في Keychain وعدم كتابتها في السجلات.
- رابط API ثابت: `https://gps.p3nd.fun/api/v1`.
- مفتاح المشروع يحقن من GitHub Secret باسم `WOLFOX_PROJECT_KEY` ولا يدخل السورس أو ملفات الإصدار.

## خريطة المدارس والمساجد

- تبويب مستقل في Lite بثلاثة أنماط: عادي، قمر صناعي، وهجين.
- مدارس 🏫 ومساجد 🕌 ومستوصفات ومراكز صحية 🏥 ومستشفيات حكومية أو عامة H من OpenStreetMap ضمن الجزء الظاهر من الخريطة.
- ظهور تدريجي حسب التكبير وتجميع العلامات لتقليل الازدحام.
- علامة المدرسة متحركة حركة خفيفة، ويظهر اسم المعلم ونوعه عند تحديده.
- ثلاث طبقات بحث متتابعة: Apple Maps ثم Geocoder ثم Nominatim/OpenStreetMap.
- ثلاثة مزودي Overpass لمعالم الخريطة لرفع الاستمرارية.

## نواتج البناء

ينتج مسار البناء الوحيد `Build WolFox 2.0.0 — Full and Lite` ما يلي:

- `WolFoxGPSLite.dylib`
- حزمة DEB Rootful وحزمة DEB Rootless بمعمارية arm64
- `WolFox-Lite-2.0.0-Deploy.zip`
- `SHA256SUMS.txt` و`RELEASE_SHA256SUMS.txt`
- `BUILD_INFO.txt` وفيه commit وrun الصحيحان من GitHub Actions
- أرشيف السورس المطابق للـ commit المبني

يعتمد الإصدار فقط بعد نجاح اختبارات Linux وفحوص Lite والترخيص والتخزين والتحقق من ملفات DEB وDYLIB والبصمات.
